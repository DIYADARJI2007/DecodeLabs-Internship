📊 DecodeLabs Project 2 – Exploratory Data Analysis (EDA)

📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python and Excel data.

The dataset contains information about cities, products, categories, sales, and related data. The main purpose of this project is to analyze the data, identify useful patterns, and present the findings through charts and summaries.

🎯 Objectives

- Analyze the given dataset.
- Clean and organize the data.
- Perform category-wise analysis.
- Perform city-wise analysis.
- Identify important patterns and trends.
- Create charts and visualizations.
- Generate a clear summary of the analysis.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Jupyter Notebook / VS Code

📈 Analysis Performed

1. Category Analysis

Category-wise data was analyzed to understand the performance and distribution of different product categories.

2. City Analysis

City-wise analysis was performed to compare data across different cities.

3. Product Analysis

Different products were analyzed based on the available dataset values.

4. Data Visualization

Charts were created to make the analysis easier to understand.

The project includes:

- 📊 Category Analysis Chart
- 🏙️ City Analysis Chart
- 📦 Product-related Analysis
- 📋 Summary Analysis

⚙️ Prerequisites

Before running the project, make sure you have:

- Python 3.x installed
- VS Code or Jupyter Notebook
- Pandas
- Matplotlib

🔧 Environment Setup

Step 1: Install Python

Download and install Python 3.x on your system.

Step 2: Install Required Libraries

Open the terminal and run:

pip install pandas matplotlib openpyxl

Step 3: Open the Project

Open the project folder in VS Code or Jupyter Notebook.

Step 4: Add the Dataset

Keep the Excel file in the project folder:

DecodeLabs_Project_2_EDA.xlsx

Step 5: Run the Analysis

Run the Python/Jupyter files to perform the analysis and generate the required charts.
